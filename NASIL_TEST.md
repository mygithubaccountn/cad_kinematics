# Robotu nasıl görürsün

Godot kurulu değilse (veya açılmıyorsa) **tarayıcı** kullan:

```bash
cd "/Users/nisa/Desktop/new cad project"
./open_viewer.sh
```

Tarayıcıda robot açılır. Sürükleyerek döndür, scroll ile zoom.
“Joint’leri hareket ettir” işaretliyse parçalar sallanır.

Durdurmak: terminalde `Ctrl+C`.
